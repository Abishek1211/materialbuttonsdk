# Material Button SDK

Reusable Android SDK for Material 3 style buttons.

## Features
- Filled Button
- Outlined Button
- Text Button
- Toggle Button
- Segmented Button Group

## Usage

```xml
<com.sdk.buttons.FilledButton
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="Login"/>
```

## Build

```bash
./gradlew assembleRelease
```
